# Докази використання

Агент запускався на зданих лабораторних роботах; здані звіти приховано від агента (`--hide`) і використано як еталон.

| Тека | Робота | Вміст |
|---|---|---|
| `mobile-lab4/` | Розробка мобільних додатків, ЛР 4 | 3 ітерації агента (`README_generated_v1..v3.md`), журнали сесій, вивід консолі, порівняння з еталоном — `comparison.md` |
| `mobile-lab3/` | Розробка мобільних додатків, ЛР 3 | згенерований `README_generated.md`, журнал сесії |
| `mmdo-lab05/` | Моделювання та аналіз ПЗ, ЛР 5 | 3 ітерації `lab05_report_generated*.md` (без зображень, PlantUML з `.puml`), журнали |
| `linux-lab5/` | Програмування для ОС Linux, ЛР 5 | фінальний звіт `ІПЗ-23-5_Лагода_ЛР5_звіт_final.md` + `.docx`, проміжні версії v1–v3, журнали |
| `chat-session/` | РМД, ЛР 4 | сесія з правкою в чаті («перевірено на Android-емуляторі, не на iOS») і звіт після правки |

Формат журналів `session*.jsonl`: один JSON-рядок на подію — `user` (повідомлення), `step` (запит до моделі: модель, токени), `tool` (виклик інструмента з аргументами і початком результату), `nudge` (повернення агента після непройденої перевірки), `api_error`, `answer` (тривалість, сумарні токени), `save`.

Скріншоти в теках `screenshots/` скопійовано з відповідних робіт, щоб посилання у згенерованих звітах відкривались.
