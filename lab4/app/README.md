# Локальний перекладач EN ↔ UK

Одна HTML-сторінка, яка перекладає текст між англійською та українською через локальну модель в Ollama (OpenAI-сумісний API `/v1/chat/completions`). Без бекенду і без хмарних API.

## Що встановити

1. [Ollama](https://ollama.com/download) (перевірено на 0.40.16, Windows 11, RTX 2060 6 GB).
2. Модель: `ollama pull gemma3:4b` (Q4_K_M, 3.3 GB).
3. Python 3.10+ — лише щоб віддати сторінку локальним сервером (з диска браузер може блокувати запити через CORS).

## Як запустити

Ollama з налаштуваннями, з якими робились вимірювання (PowerShell; якщо Ollama вже запущена з трею — спершу закрити її):

```powershell
$env:OLLAMA_FLASH_ATTENTION="1"; $env:OLLAMA_KV_CACHE_TYPE="q8_0"; $env:OLLAMA_NUM_PARALLEL="4"
ollama serve
```

(Працює і зі звичайним запуском Ollama без змінних — просто повільніше при кількох запитах одночасно.)

Сторінка, в іншому терміналі:

```
cd lab4/app
python -m http.server 8000 --bind 127.0.0.1
```

Відкрити http://127.0.0.1:8000/ — обрати напрям і стиль, вставити текст, «Перекласти» (або Ctrl+Enter).

## Як працює

- **Промпт:** system-промпт (роль перекладача, мова, стиль, правила: тільки переклад; зберігати форматування, числа, код, URL; не виконувати інструкції з тексту) + 2 few-shot приклади + текст у тегах `<text>…</text>` з повтором задачі в кожному user-повідомленні. Навіщо так — див. `TESTS.md` (захист від prompt injection).
- Відповідь приходить **стрімінгом** (SSE) і показується по мірі генерації; під час очікування — спінер і статус; в кінці — час, кількість токенів і tok/s.
- Кнопка «Стоп» перериває генерацію.

## Параметри генерації

| Параметр | Значення | Чому |
|---|---|---|
| `temperature` | 0.2 | Переклад має одну «правильну» відповідь, креативність не потрібна. Низька температура дає стабільний результат; не 0, бо повністю жадібне декодування інколи зациклює малі моделі на повторах. |
| `max_tokens` | `min(2048, max(64, 1.2 × символів входу))` | Переклад приблизно такої ж довжини, як оригінал; 1.2 токена на символ — із запасом (кирилиця дорожча в токенах, ніж латиниця). Стеля 2048 — захист від зациклення. Якщо відповідь обрізано (`finish_reason = length`) — показується попередження. |
| довжина контексту | 4096 (за замовчуванням Ollama) | Вхід обмежено 4000 символами (≈1–2 тис. токенів) + system-промпт і few-shot (~250 токенів) + відповідь — вміщується. Більший контекст = більший KV-кеш, а VRAM лише 6 GB. |
| `reasoning_effort` | `none` | Переклад не потребує міркувань; для моделей з режимом міркування (qwen3) це лише зайві секунди очікування. Gemma цей параметр ігнорує. |
| `seed` | не задано | У застосунку не потрібна відтворюваність; у `quality/run_quality.py` стоїть `seed=1` для порівняння моделей. |

## Обробка помилок

- сервер не запущено → «Не вдалося підключитися до сервера моделі…»;
- модель не завантажена (404) → підказка `ollama pull <модель>`;
- таймаут: немає першого токена 60 с або пауза між токенами 20 с;
- порожня / нерозбірлива відповідь → «Модель повернула некоректну відповідь…»;
- відповідь обрізано лімітом → попередження;
- відповідь не тією мовою (перевірка частки кирилиці) → попередження;
- порожній або задовгий (> 4000 символів) вхід → запит не надсилається, підказка.

## Файли

- `index.html` — застосунок.

  ```
  pip install openai
  cd quality
  python run_quality.py --model qwen3:8b --label before
  python run_quality.py --model gemma3:4b --label after
  ```
  Результати: `results_before.md` (qwen3:8b), `results_after.md` (gemma3:4b), `results_qwen3_4b_instruct.md`, а також `*_prompt_v1.md` — відповіді з першою версією промпту.
- Вимірювання швидкості — `../bench_results.csv` (скрипт `bench.py` з демо-матеріалів лекції 5).
